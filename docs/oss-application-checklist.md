# OSS Application Checklist

这份清单用于申请开源项目支持计划前自查，尤其适合 Codex for OSS 这类维护者申请。

## 已具备

- 公开仓库
- 原创项目
- MIT License
- README 说明项目定位和使用方式
- `AGENTS.md` 支持 Codex 风格 agent
- `CLAUDE.md` 支持 Claude Code
- 贡献指南
- 路线图
- Issue / PR 模板
- 最小示例

## 还需要加强

- 发布一个正式 release
- 补充 1-2 个真实完整案例
- 增加近期有意义的维护提交
- 收集真实用户反馈或试用记录
- 增加更多模型适配说明
- 修复用户首次运行时可能遇到的配置问题

## 申请时可以强调

- 维护者是原作者，并有仓库 admin 权限
- 项目已经在真实 PPT 制作中验证过
- 项目目标和 AI coding agent 高度相关
- Codex 可以帮助维护文档、模板、脚本、issue、PR 和示例
- 当前是早期项目，不夸大 stars 或用户量

## 申请时不要强调

- 不要声称已经有大量用户
- 不要声称已经有很多外部贡献
- 不要把 demo、课程项目或 fork 当作生态影响力
- 不要使用刷 star、假 issue、假 PR 等方式制造数据
