# Maintenance Notes

This document explains how the project is maintained and where help is useful.

## Maintainer Role

The repository is maintained by its original author. The maintainer is responsible for:

- keeping the template usable for real PPT projects
- improving agent instructions for Claude Code, Codex, and Cursor
- reviewing issues and pull requests
- adding examples from real usage
- keeping secrets and generated files out of the public repository

## Current Maintenance Focus

The current focus is practical adoption:

- make the first-run experience clearer
- document the page-by-page workflow
- improve error handling for image generation
- collect reusable Prompt patterns
- support more agent environments through `AGENTS.md` and `CLAUDE.md`

## Where AI Coding Agents Help

AI coding agents are useful in this project because the work is mostly structured maintenance:

- turn real user feedback into issue triage
- update workflow docs without changing the core idea
- adapt image API providers
- generate example page scripts
- check file paths and project structure
- prepare small PRs for templates, docs, and helper scripts

The maintainer still makes final decisions on visual direction, project scope, and accepted changes.
