# 03 - Prompt 编写模式库

> 以下经验全部来自真实项目的 70+ 次迭代，每条都踩过坑。

## 铁律一：文字位置必须精确

**错误写法：**
```
标题居中显示
```

**正确写法：**
```
画面中央偏上位置（垂直方向约 1/3 处），超大加粗金色金属质感字体：「你的标题」
这是画面最醒目的文字元素，不能被背景元素遮挡。
```

为什么："居中"在 AI 理解中可能是视觉中心、几何中心、或者"大概在中间"。你必须说清楚是"中央偏上"还是"中央偏下"，否则文字会被主体元素遮挡。

## 铁律二：颜色必须逐字指定

**错误写法：**
```
标题用金色文字
```

**正确写法：**
```
标题文字颜色：
- "纯课堂学习"五个字用金色金属质感
- 逗号用白色
- "不是我的最优解"用金色金属质感
副标题"开辟第二个赛道"用白色
```

为什么：AI 对"金色文字"的理解是把整段都变成金色，包括你可能不想加颜色的部分。如果标题里有不同颜色的词，必须逐字说清。

## 铁律三：主体元素优先级要强调

**错误写法：**
```
画面中有一只凤凰和一些文字
```

**正确写法：**
```
画面主体是一只金色凤凰（占画面高度的 60%），凤凰是最重要的视觉元素，
任何文字和装饰元素都不能遮挡凤凰主体。
文字排列在凤凰上方和下方的空白区域。
```

为什么：AI 不会自动判断哪个元素更重要，它可能把文字叠在凤凰脸上。你需要明确说"不能被遮挡"。

## 铁律四：参考图是最强的风格锚定工具

参考图的作用不是让 AI 照抄，而是：
1. **锚定全局风格** — 色调、质感、光影层次
2. **锚定布局结构** — 导航栏位置、文字区域、留白比例
3. **锚定设计语言** — 3D 还是扁平，写实还是抽象

**最佳实践：**
```
以附带的参考图为基础，保持相同的整体风格、3D渲染质感和深蓝色背景色调。
在参考图的布局基础上，做以下调整：
1. 主体元素从 X 改为 Y
2. 文字内容从 A 改为 B
3. 色调增加更多金色暖光
```

经验：**已被确认的页面 + 参考图 + 少量修改 = 最稳的策略**。

## 铁律五：少改优于大改

当一页已经被确认过基本风格后：

- **不要重新描述整个画面**，用参考图 + 增量修改
- **不要一次改多个元素**，改一个，确认后再改下一个
- **不要换风格**，在现有风格基础上微调

**反面教材：** 老师说"这页文字位置偏了"，你把整页重新描述了一遍 → 生成的图完全变了，老师说"原来那版更好"。

**正确做法：** 参考图用当前这页，Prompt 里只说"把文字从中央偏上移到中央偏下，其他所有元素保持不变"。

## 铁律六：重复元素必须每页详细描述

如果你的 PPT 有统一的导航栏、页码、logo 等重复元素：

```
【顶部导航栏——与参考图保持完全一致的样式和位置】
顶部导航栏四个区块从左到右依次为：
1.「1%的遗憾」—— 普通灰色，不高亮
2.「1%的觉醒」—— 金色边框高亮，文字为金色，表示当前章节
3.「100%的实战」—— 普通灰色，不高亮
4.「∞的可能」—— 普通灰色，不高亮
导航栏的大小、间距、字体、位置与参考图完全一致。
```

**每一页都要写这段**，不能省略。AI 没有跨页记忆，你省掉了它就会自由发挥。

## 模式一：Prompt 的标准结构

```
生成一张PPT内页图片（16:9比例）。

以附带的参考图为基础，保持相同的整体风格和色调。

【顶部导航栏】
（详细描述每个区块、高亮状态、样式）

【背景与主体画面】
（整体背景色、3D 场景描述、主要视觉元素）

【文字内容——必须严格按以下位置和颜色】
（标题位置、字号、颜色、副标题、数据、金句，逐个描述）

【不要出现的元素】
（可选，明确排除不想要的东西）
```

## 模式二：数据可视化页面

数据页需要特别注意：

```
【数据区域——画面右侧，占宽度 40%】
三个数据块从上到下排列：

第一个数据块：
- 大字"110%"，金色，字号超大
- 下方小字"2025年四季度"，白色
- 再下方"算法岗位需求同比增长"，白色

第二个数据块：
- 大字"¥35K"，金色
- 下方"平均月薪"，白色

（数据的顺序、大小、颜色都要逐个写清楚）
```

## 模式三：多方案对比生成

当不确定风格方向时，用一次生成出多个方案：

```python
# gen_风格对比.py
PROMPTS = {
    "风格A_破冰而出": "...（实体凤凰破冰而出的描述）...",
    "风格B_光芒凝聚": "...（光粒子凝聚成凤凰的描述）...",
    "风格C_冰裂凤凰纹": "...（裂纹构成凤凰形状的描述）...",
}

for name, prompt in PROMPTS.items():
    gen(prompt=prompt, page_dir=..., count=1, prefix=f"{name}_v")
```

每种风格只生成 1 张用于对比，确定方向后再对选中风格生成 3 张。

## 常见问题速查

| 问题 | 原因 | 解决 |
|------|------|------|
| 文字被背景元素遮挡 | 没说优先级 | 加"文字区域不能被遮挡" |
| 导航栏每页长得不一样 | 省略了描述 | 每页都写完整导航栏描述 |
| 生成的图和参考图风格差异大 | Prompt 描述了太多新元素 | 减少改动量，用参考图+微调 |
| 文字颜色不对 | 笼统说了"金色" | 逐字指定颜色 |
| 画面元素太多太乱 | Prompt 里堆了太多要求 | 减少元素，一页只突出一个重点 |
| 3 张候选图都不行 | Prompt 方向有问题 | 先做方案对比，确定方向再细化 |
