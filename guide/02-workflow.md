# 02 - 完整工作流

## 总览

```
┌──────────────────────────────────────────────────────────┐
│              Phase 1：项目初始化（一次性）                  │
│  配置 API → 导入内容 → 确定视觉风格 → 分页规划            │
│  完成后 Phase 1 从 CLAUDE.md 中删除                       │
└────────────────┬─────────────────────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────────────────────┐
│          Phase 2：首版制作（0 → 1，快速完成所有页面）       │
│                                                          │
│  读 progress.md → 确认当前页 → 讨论画面 → 写 gen.py      │
│  → 生成 3 张候选 → 用户选图 → 确认结束 → /done           │
│  → 下一页（建议开新对话）                                 │
└────────────────┬─────────────────────────────────────────┘
                 │ 所有页面完成后
                 ▼
┌──────────────────────────────────────────────────────────┐
│          Phase 3：迭代优化（基于反馈针对性修改）            │
│                                                          │
│  收集反馈 → 写修改计划 → 逐页修改                        │
│  修改文件放入 rev1/ / rev2/ 子目录                        │
│  可多轮修改，每轮独立修改计划                             │
└──────────────────────────────────────────────────────────┘
```

## Phase 1: 项目初始化

由 CLAUDE.md 自动引导，只执行一次。完成后 Phase 1 内容从 CLAUDE.md 中删除以节省上下文。

### 1.1 配置 API
创建 `.env` 文件，填入图片生成 API 的 URL、密钥、模型名称。

### 1.2 导入内容
将演讲稿或文案放入 `content/` 目录。

### 1.3 确定视觉风格
AI 提供预设方向，用户选择或自定义。确定后写入 CLAUDE.md 的"视觉风格"章节。

### 1.4 分页规划
AI 建议分页方案，用户确认后，AI 在内容文档中插入页码标记（`<!-- 第01页：封面 -->`），创建目录结构和 `progress.md`。

## Phase 2: 首版制作

### 每页制作流程

1. **读计划** — 读 `progress.md`，确认当前做哪页
2. **读内容** — 读 `content/` 文档中对应页码标记的段落
3. **讨论画面** — 和用户确认构想（不过度纠结，80分就过）
4. **参考图** — 询问用户是否使用参考图（建议使用）
5. **写 gen.py** — 创建 `ppt-pages/XX/init/gen.py`
6. **生成候选** — 执行脚本，并发生成 3 张候选图
7. **用户选图** — 必须问用户选哪张
8. **不满意** → 调整 prompt，新建 `gen_v2.py`，重新生成
9. **满意** → AI 问"这一页结束了吗？" → 用户确认 → 执行 `/done`

### 每页完成时（/done skill 自动执行）

1. 询问是否导出参考图到 `ppt-ref-images/`
2. 写制作记录到 `ppt-pages/制作记录/首版/XX.md`
3. 更新 `progress.md`
4. Git 提交（单页粒度）
5. 引导用户开新对话继续下一页

## Phase 3: 迭代优化

用户拿到反馈后进入此阶段。

### 流程

1. **收集反馈** — 用户描述收到的反馈
2. **写修改计划** — 创建 `ppt-pages/制作记录/修改计划-vN.md`
3. **逐页修改** — 修改文件放入 `ppt-pages/XX/rev1/`（第二轮 `rev2/`）
4. 每页流程同 Phase 2（讨论 → 生成 → 选图 → 确认 → /done）

## 并行工作

多页 PPT 可以同时开多个 Claude Code 窗口并行制作：

- 每个窗口只碰自己那一页的文件
- 共享文件（CLAUDE.md、参考图）只读
- Git 提交时只 add 自己页面的文件
- 参考图是只读资源，多个窗口可以引用同一张
