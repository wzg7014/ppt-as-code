# 完成当前页面

当用户确认当前页满意并结束时，执行以下流程。

前提：用户已经告知选了哪张候选图（v1/v2/v3）。

## 1. 询问参考图导出

询问用户：是否将选定的图导出到 `ppt-ref-images/` 作为后续页面的参考图？（建议导出）

如果是，将选定图复制到 `ppt-ref-images/` 并以页码命名（如 `01.png`）。

## 2. 写制作记录

根据当前阶段写入对应目录：
- 首版制作 → `ppt-pages/制作记录/首版/XX.md`
- 修改 → `ppt-pages/制作记录/修改/revN-XX.md`

记录内容：
- 页码和内容主题
- 使用的 Prompt（完整）
- 是否使用参考图及路径
- 3 张候选各自的特点
- 用户选了哪张、原因
- 迭代过程（如果不止一轮）

## 3. 更新 progress.md

在页面状态表中填入 `done` 和用户选择的候选编号。

## 4. Git 提交

单页粒度提交，包含：
- 当前页目录下的所有文件（gen.py + 全部候选图）
- 对应的制作记录
- progress.md

Commit message 格式：
- 首版：`第XX页首版：内容概要`
- 修改：`第XX页修改(revN)：改动概要`

## 5. 引导下一步

告知用户：
> 这一页完成了。建议开一个新对话，说"继续"来做下一页。

如果是最后一页，告知首版制作全部完成。
